# Job Portal API

Live API: https://job-portal-api-cz2q.onrender.com 
## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Hibernate
- Postman

## Features
- User Registration
- User Login
- JWT Authentication
- User Profile API
- Job CRUD Operations
- Job Search By Company
- Job Search By Title
- Pagination
- Resume Upload
- Resume Download
- Job Applications
- Application Status Tracking

## APIs
- /api/users/*
- /api/jobs/*
- /api/resume/*
- /api/applications/*

## Tools Used
- IntelliJ IDEA
- MySQL Workbench
- Postman
- GitHub
